# Evidencia

Screenshots de las fuentes oficiales, con la cita resaltada y la URL y la fecha estampadas abajo. Cada entrada de `entidades.yaml` enlaza la suya en `captura`, como `evidencia/<id>.png`.

Se toman con:

```sh
node scripts/screenshot-sources.mjs <rama-base> content/co/evidencia
```

Si la página bloquea el acceso automático o la cita está oculta, la screenshot no muestra el dato y no se guarda: se toma a mano desde un navegador, sin datos personales ni sesiones abiertas.

## Derechos

Las imágenes reproducen páginas de cada entidad y les pertenecen. Se incluyen solo como evidencia de dónde sale cada dato. No se publican bajo la licencia del proyecto: ni AGPL-3.0 ni la CC BY-SA 4.0 del resto de `content/`.
